## Ненарисованные экраны — собирать из компонентов

| Экран | Маршрут | Схема сверху вниз |
|---|---|---|
| Вход | `login.tsx` | логотип (файл из `assets/brand`) по центру верхней трети → `display` «Помощь с машиной рядом» → `bodySm` подзаголовок → кнопки «Войти через Google» (`secondary`, иконка), «Войти по email» (`primary`) → `ghost` «Продолжить без входа» |
| Заказы клиента | `client/orders.tsx` | заголовок `title` → чипы «Активные / Завершённые» → список карточек заказа (как MasterCard: услуга, машина, бейдж статуса, цена) → EmptyState «Заказов пока нет» |
| Чаты | `client/chats.tsx`, `specialist/chats.tsx` | заголовок → строки: аватар 48, имя 600, последнее сообщение `ink2` 1 строка, время 12 `ink3`, счётчик-кружок `brand` |
| Гараж | `client/garage.tsx` | заголовок → карточки машин (марка/модель `subheading`, год и госномер `bodySm`, иконка `car-outline`) → Button `secondary` «Добавить машину» → EmptyState |
| Профиль | `client/profile.tsx` | аватар 72 + имя `title` → список строк (высота 56, иконка 24, текст `body`, шеврон): Мои данные, Тема (Системная/Светлая/Тёмная), Язык (Русский/Қазақша), Режим мастера (переключатель режима), Помощь → `danger` «Выйти» |
| Заказ, шаги 1–2 | `orders/new.tsx` | шапка с `overline` «Шаг N из 3» и прогресс-полосой 4 → шаг 1: выбор машины из гаража или поле марка/модель + поле «Ссылка на объявление» → шаг 2: адрес (TextField с иконкой) + дата/время (чипы «Сегодня / Завтра / Выбрать») → CTA-панель `primary` «Далее» |
| Кабинет мастера | `specialist/index.tsx` | переключатель «На линии» → 3 цифры (заказы сегодня, рейтинг, заработано) в карточке как на экране 02 → баннер «Профиль на проверке» (info) до верификации → ближайший заказ (OrderTracker в карточке) |
| Профиль мастера (редактирование) | `specialist/profile.tsx` | аватар → услуги и цены (строки с ценой справа, кнопка «Добавить услугу») → оборудование (чипы) → документы для проверки (строки со статус-бейджами) |
