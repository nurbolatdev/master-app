# Сквозные паттерны

## 1. Четыре состояния экрана

Каждый экран с данными реализует все четыре (правило проекта):

| Состояние | Как выглядит | Компоненты |
|---|---|---|
| **Загрузка** | Скелетоны в форме будущего контента (`surface2`, те же скругления и размеры), без полноэкранного спиннера. Если загрузка > 10 с — текст «Загружаем дольше обычного…». | Skeleton-версии карточек |
| **Пусто** | Объяснение + одно действие | EmptyState |
| **Ошибка** | Что случилось + «Повторить». Текст ошибки — по `ErrorCode` из i18n (`errors.*`). | Banner danger или EmptyState с кнопкой |
| **Нет сети** | Banner danger «Нет интернета» вверху контента; уже загруженные данные остаются; действия ставятся в очередь, где это безопасно (сообщения, SOS) | Banner |

Порядок проверки в коде: нет сети → ошибка → загрузка → пусто → данные.

## 2. Навигация

- Два режима: клиент и мастер, у каждого свои 5 вкладок (см. `components.md` → BottomNav). Переключение режима — в Профиле.
- Всё, что глубже вкладки (профиль мастера, заказ, чат, отчёт), открывается **стеком поверх таб-бара** (таб-бар скрыт).
- SOS — модальное окно на весь экран, закрывается крестиком, жест «назад» спрашивает подтверждение, если плитка уже выбрана.
- Кнопка «Назад» — круг 48 слева сверху; системный жест/кнопка «назад» работает везде.
- Deep links (`masterapp://`): `orders/{id}`, `chats/{id}`, `specialists/{id}`, `orders/{id}/report` — из push-уведомлений открывается нужный экран.

## 3. Экранная сетка

- Поля 16, между секциями 24, внутри карточки 16.
- Шапка: safe area + 12 сверху. Крупный заголовок экрана — `typography.title`.
- Нижняя CTA-панель: фон `surface`, линия сверху `border`, паддинг 12×16, снизу safe area (≥ 16). Контент над ней не прячется.
- Ширина экрана 360–430: всё тянется по ширине, сетки (плитки 4/2 колонки) остаются, меняется ширина колонок.

## 4. Формы

- Подпись над полем всегда; плейсхолдер — только пример значения.
- Валидация — при уходе с поля и при отправке; ошибка под полем с подсказкой, как исправить.
- Кнопка отправки не блокируется заранее «потому что форма не заполнена» — при нажатии показываются ошибки и фокус уходит к первому неверному полю.
- Клавиатуры: телефон — `phone-pad`, суммы — `number-pad`, email — `email-address`.
- Шаги мастера (визард): `overline` «Шаг N из M» + полоса прогресса; «Назад» возвращает на шаг, данные сохраняются.

## 5. Форматирование

| Что | Формат | Пример |
|---|---|---|
| Деньги | тысячи через неразрывный пробел, «₸» после числа | `15 000 ₸`, `от 60 000 ₸` |
| Крупные суммы в тексте | сокращение | `12,9 млн ₸` |
| Расстояние | < 1 км — метры, иначе км с одной цифрой после запятой | `800 м`, `1,2 км` |
| Время до приезда | минуты, «~» если оценка | `~15 мин`, `через 12 мин` |
| Время | 24 часа | `14:58` |
| Дата | «сегодня», «вчера», иначе «12 ноября» (год, если не текущий) | `12 ноября 2025` |
| Телефон | `+7 701 234 56 78` | — |
| Госномер | как на номере, капсом, с разрядкой | `123 ABC 02` |
| Рейтинг | одна цифра после точки | `4.9` |

Использовать `Intl.NumberFormat("ru-KZ")` / `("kk-KZ")` и общий модуль форматтеров, не собирать строки вручную в компонентах.

## 6. Локализация

- Каждая строка — ключ i18n, ru и kk добавляются одновременно (правило проекта).
- Казахские строки в среднем длиннее: кнопки и чипы не имеют фиксированной ширины, текст переносится, а не обрезается многоточием (кроме имени в одну строку).
- Плюрализация — средствами i18next (`_one`, `_few`, `_many` для ru).
- Имена ключей — по экрану: `client.home.*`, `orders.new.*`, `orders.track.*`, `report.*`, `chat.*`, `sos.*`, `specialist.feed.*`, `specialist.profile.*`.

## 7. Обратная связь

- Нажатие — визуальный отклик ≤ 120 мс.
- Действие с сетью — состояние loading в самой кнопке.
- Успех — тост сверху (`zIndex.toast`) на 3 с: иконка `success` + текст, или смена экрана.
- Опасное действие (отмена заказа, выход) — подтверждение в нижнем листе: заголовок, последствия, `danger` кнопка действия + `secondary` «Не отменять».
- Haptics: успех отправки заказа/SOS и новая срочная заявка у мастера — `notificationAsync(Success)`; больше нигде.

## 8. Доступность

- Порядок фокуса скринридера = визуальный порядок.
- Иконки рядом с текстом — `accessibilityElementsHidden`/`importantForAccessibility="no"`.
- Карточка мастера читается одной фразой: «Ержан Сапаров, проверен, рейтинг 4,9, 127 отзывов, 1,2 километра, от 15 000 тенге».
- Изменение статуса заказа и ошибки форм объявляются (`accessibilityLiveRegion` / `AccessibilityInfo.announceForAccessibility`).
- Крупный системный шрифт: строки переносятся, высоты растут; проверять при 130% и 200%.
