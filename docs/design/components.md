# Компоненты

17 компонентов интерфейса. Для каждого: где лежит эталон, анатомия в dp, варианты, состояния, токены и как собрать в React Native. Эталон в обеих темах: `reference/components/<Имя>.html` и `reference/png/components/<Имя>.png`.

Рекомендуемое место в коде: `apps/mobile/src/components/ui/<Имя>.tsx` — по одному компоненту на файл, только токены из `theme.ts`, цвета через `useTheme()` (хук возвращает `colors[scheme]`). Пропсы — как в блоке «API» (это рекомендация, не контракт).

Общие правила для всех:
- Тач-цель ≥ 48 dp (если визуально меньше — `hitSlop`).
- Нажатие: смена цвета фона за 120 мс (`Pressable` + `style={({ pressed }) => …}`), на Android дополнительно `android_ripple`. Без масштабирования.
- `accessibilityRole`, `accessibilityLabel` у всего кликабельного без текста, `accessibilityState` для disabled / selected / busy.
- Тексты — только из i18n.

## 1. Button

Эталон: `reference/components/Button.html`

| Вариант | Фон | Текст/иконка | Рамка | Когда |
|---|---|---|---|---|
| `primary` | `action` | `onAction` | — | Обычное главное действие |
| `brand` | `brand`, нажатие `brandPress` | `onBrand` | — | Один ключевой шаг на экран: «Подтвердить заказ», «Вызвать эвакуатор» |
| `secondary` | `surface` | `ink` | 1.5 `borderStrong` | Пары: «Написать» / «Позвонить», «Отклонить» |
| `ghost` | прозрачный | `ink` | — | «Пропустить», «Подробнее» |
| `danger` | прозрачный | `brandText` | — | «Отменить заказ» |

Размеры: `md` — высота 52, паддинг по горизонтали 20, скругление `radius.md` (12). `sm` — высота 40 (+ `hitSlop` 4 до 48), паддинг 16, скругление 10, текст 14. Блочная (`block`) — ширина 100%.
Текст: `typography.label` (Inter 600, 15/20). Иконка слева 24 (в `sm` — 16), отступ до текста 8.

Состояния:
- **disabled** — фон `surface2`, текст `ink3`, без рамки; рядом подсказка, почему недоступно.
- **loading** — спиннер 18 (`ActivityIndicator` цвета текста) слева + новый текст («Отправляем…»), кнопка заблокирована, ширина не меняется.
- **focus** (клавиатура/TV) — кольцо 3 `trust` с отступом 2.

API: `variant`, `size: "md" | "sm"`, `label`, `icon?`, `block?`, `loading?`, `disabled?`, `onPress`.

Существующий `components/Button.tsx` заменить этим компонентом (старые варианты `primary`/`secondary` сохраняют смысл).

## 4. MasterCard (карточка специалиста)

Эталон: `reference/components/MasterCard.html`

Карточка: фон `surface`, рамка 1 `border`, скругление 16, паддинг 16, `shadow.card`. Сетка: аватар 56 + колонка (зазор 12).

Колонка сверху вниз (зазор 4):
1. Имя (Inter 600 16/22) + значок «Проверен» 18 цвета `trust` (только если мастер верифицирован админом).
2. Специализация и стаж — `bodySm`, `ink2`.
3. Рейтинг (компонент Rating, компактный) + «1,2 км · ~15 мин» `bodySm` `ink2` — в строку с зазором 12.
4. До 2 бейджей (Badge) с зазором 6, отступ сверху 4.

Подвал: отделён линией 1 `border`, отступы сверху 12/12; слева цена `от` (подпись 13 `ink2` + `typography.price`), справа Button `primary` `sm` «Выбрать».

Аватар: круг 56, `surface2`, инициалы Unbounded 700 18; онлайн — зелёная точка 14 `success` с обводкой 2 `surface` в правом нижнем углу.

Варианты:
- **Новый мастер** (0 отзывов) — бейдж `neutral` «Новый мастер» вместо рейтинга.
- **Занят** — бейдж `warning` «Занят до 16:00», кнопка «Записаться».
- **Нет цены** — вместо цены «Цена после осмотра» + иконка info.
- **Компактная** (в шторке) — без тени, рамка остаётся.

Вся карточка нажимается → профиль мастера (экран 02); кнопка «Выбрать» — отдельная цель.

## 6. Rating

Эталон: `reference/components/Rating.html`

**Компактный:** звезда 16 (`star`, заливка) + число Inter 700 14/20 `ink` + «(127)» Inter 400 14 `ink2`, зазор 4.
**Ввод оценки:** 5 звёзд по 20 (зазор 2), каждая с тач-зоной 48; пустая — заливка `surface2`, обводка 1 `borderStrong`. Под звёздами подпись словами: 1 «Плохо», 2 «Так себе», 3 «Нормально», 4 «Хорошо», 5 «Отлично». `accessibilityRole="adjustable"`.
После оценки 1–3 — обязательные чипы «Что пошло не так?»: Опоздал, Цена выросла, Грубость, Качество, Другое.
